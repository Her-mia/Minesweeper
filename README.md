# Minesweeper 

This program is a classic minesweeper game made by my brother, who just started learning Python a year ago. This program is a milestone in his programing journey. 

## About Features
This is a terminal-based version of the classic Minesweeper game, where players uncover tiles on a grid while avoiding hidden mines. It was created as a personal learning project and showcases fundamental programming concepts like:

  1. Grid-based logic
  
  2. Recursion and loops
  
  3. User input handling
  
  4. Timer
  
  ## How to Run
1. Clone or download this repository.

2. Open a terminal and navigate to the project folder.

3. Run the game

## What did he learn from this project?

- Logical thinking and problem-solving
- Managing game state and user interaction
- Building a complete, playable game from scratch
